# JavaTest

我的 Java 学习练习仓库（黑马程序员 2026 版 AI+Java 课程配套练习）。

## 目录结构

| 目录 | 内容 |
|---|---|
| `HelloWorld` | 基础语法练习（流程控制、数组、方法、Scanner、运算符等） |
| `JavaApiTest` | 常用 API 练习（String、StringBuilder、ArrayList、Random 等） |
| `OOPTEST` / `OOPTEST2` | 面向对象练习（封装、继承、多态、final、枚举等） |
| `oop-interface` / `oop-polymorphic` / `oop-innerclass` | 面向对象专题练习（接口、多态、内部类） |
| `SORT` | 排序算法练习（选择排序等） |

## 说明

本仓库用于日常练手，代码均为课堂练习，持续更新中。
